# نظام إدارة الحضور والموارد البشرية

تطبيق ويب بسيط لإدارة حضور وانصراف الموظفين وطلبات الإجازات والمرتبات والإعلانات الداخلية. المشروع مناسب كـ Graduation Project ويعمل افتراضيًا باستخدام SQLite بدون الحاجة لتثبيت سيرفر قاعدة بيانات.

## التقنيات المستخدمة

- Python
- Flask
- Flask-SQLAlchemy
- SQLAlchemy
- SQLite افتراضيًا
- دعم اختياري لـ PostgreSQL و MySQL من خلال `DATABASE_URL`
- Bootstrap و HTML Templates

## أهم وظائف التطبيق

- تسجيل دخول للمدير والموظفين.
- لوحة تحكم للمدير.
- إدارة الموظفين.
- تسجيل الحضور والانصراف.
- تحديد نطاق جغرافي للحضور.
- رفع صورة الموظف وصورة الحضور.
- عرض سجل الحضور والانصراف.
- طلب إجازة من الموظف.
- قبول أو رفض طلبات الإجازات من المدير.
- حساب المرتبات حسب عدد ساعات العمل.
- حفظ مفردات المرتب وعرضها للموظف.
- نشر إعلانات الشركة والتعليقات عليها.

## إعداد قاعدة البيانات

التطبيق يستخدم SQLAlchemy، لذلك يمكن تغيير قاعدة البيانات من ملف `.env`.

الإعداد الافتراضي هو SQLite:

```env
DATABASE_URL=sqlite:///hr_management.db
```

مثال PostgreSQL:

```env
DATABASE_URL=postgresql+psycopg://user:password@localhost:5432/hr_management
```

مثال MySQL:

```env
DATABASE_URL=mysql+pymysql://user:password@localhost:3306/hr_management
```

للمشروع الطلابي، يُنصح باستخدام SQLite لأنه لا يحتاج إلى إعدادات إضافية.

## ملف البيئة `.env`

مثال محتوى ملف `.env`:

```env
DATABASE_URL=sqlite:///hr_management.db
SECRET_KEY=change-this-for-demo
```

لا تضع ملفات البيئة أو كلمات السر الحقيقية في GitHub إذا كان المشروع عامًا.

## ملاحظات للفريق

- SQLite هي قاعدة البيانات الافتراضية والأسهل للديمو.
- يمكن تغيير قاعدة البيانات بدون تعديل الكود، فقط بتغيير `DATABASE_URL`.
- الصور المرفوعة يتم حفظها داخل `static/uploads`.
- قاعدة البيانات يتم إنشاؤها تلقائيًا عند تشغيل `app.py`.
- إذا تم حذف ملف قاعدة البيانات، سيعيد التطبيق إنشاء الجداول وحساب المدير الافتراضي عند التشغيل التالي.
